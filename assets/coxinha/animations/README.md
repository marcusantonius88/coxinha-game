# Coxinha — sprites para Phaser 3

Arquivos PNG RGBA com transparência. Cada quadro foi normalizado para 48×32 px e os pés
foram alinhados à mesma linha de base.

Spritesheets horizontais:
- `coxinha_idle_spritesheet.png` — IDLE, 4 quadros (entrega anteriormente aprovada)
- `coxinha_walk_spritesheet.png` — WALK, 8 quadros
- `coxinha_run_spritesheet.png` — RUN, 8 quadros
- `coxinha_jump_spritesheet.png` — JUMP, 6 quadros
- `coxinha_fall_spritesheet.png` — FALL, 4 quadros
- `coxinha_land_spritesheet.png` — LAND, 4 quadros

Cada estado inclui também os PNGs individuais na pasta de mesmo nome e uma prévia ampliada.
As novas poses foram extraídas de strips gerados com referência ao Coxinha enviado pelo usuário;
o fundo magenta foi removido automaticamente. Confira `preview-geral.png` e as prévias individuais
antes da integração: o processamento técnico está feito, mas a aprovação visual final ainda é
necessária. Nenhum código ou física do jogo foi alterado.
